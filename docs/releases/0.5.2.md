## Upgrade notes

1. **Launch ensures the declared fleet roles have AMQ mailboxes.** If any are
   missing, `agentctl launch` runs `amq init` before starting roles. Existing
   sessions and their mail are untouched.
2. **AMQ setup failure refuses launch.** If `amq init` fails, launch stops and
   prints AMQ's own error verbatim.
3. **`agentctl run` is unchanged.**
