# Third-party license materials

agentctl release archives include the license materials for every third-party
module linked into the binary:

- `github.com/santhosh-tekuri/jsonschema/v6` v6.0.3 — the upstream `LICENSE`
  is reproduced at `github.com/santhosh-tekuri/jsonschema/v6/LICENSE`.
- `golang.org/x/text` v0.14.0 — the upstream `LICENSE` and `PATENTS` are
  reproduced at `golang.org/x/text/LICENSE` and
  `golang.org/x/text/PATENTS`.

The module versions are pinned in `go.mod`. The files named above are copied
from those exact downloaded module versions without modifying their text.
